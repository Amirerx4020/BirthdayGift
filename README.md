# هدیه‌ی تولد با تایید تلگرام

سایتی که یه کد گیفت کارت پلی‌استیشن رو بعد از تایید هویت با ربات تلگرام نشون می‌ده.

## چطور کار می‌کنه

1. دوستت QR کد رو اسکن می‌کنه و وارد سایت می‌شه.
2. سایت ازش شماره موبایل می‌خواد.
3. سرور شماره رو با شماره‌ی واقعی دوستت (که از قبل تنظیم کردی) مقایسه می‌کنه.
4. اگه درست بود، یه دکمه نشون داده می‌شه که مستقیم به یه ربات تلگرام با یه توکن یک‌بارمصرف وصل می‌شه.
5. دوستت دکمه رو می‌زنه، تلگرام باز می‌شه، دکمه‌ی START رو می‌زنه، و بات فوراً کد اصلی گیفت کارت رو براش می‌فرسته.

کد اصلی گیفت کارت فقط روی سرور (متغیر محیطی) نگه‌داری می‌شه، هیچ‌وقت تو فایل‌های فرانت‌اند یا جواب API قرار نمی‌گیره؛ فقط از طریق پیام تلگرام دیده می‌شه. توکن هم یک‌بارمصرفه، بعد از استفاده باطل می‌شه.

> نکته: تلگرام به بات‌ها اجازه نمی‌ده مستقیم و خودکار به یه شماره یا آیدی دلخواه پیام بفرستن (به‌خاطر حریم خصوصی). به همین خاطر دوستت باید یه‌بار خودش دکمه‌ی استارت رو تو تلگرام بزنه؛ لینک دیپ‌لینک این کار رو تقریباً به یه تپ ساده تبدیل می‌کنه.

## مرحله ۱: ساخت ربات تلگرام

1. تو تلگرام برو سراغ [@BotFather](https://t.me/BotFather).
2. بزن `/newbot` و اسم و یوزرنیم دلخواه رو انتخاب کن (یوزرنیم باید به `bot` ختم بشه، مثلاً `Sara_Birthday_bot`).
3. یه توکن بهت می‌ده، شبیه این: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. این رو نگه دار.

## مرحله ۲: دیپلوی (میزبانی رایگان)

این پروژه یه سرور Node.js ساده‌ست (نه فقط یه فایل استاتیک)، چون باید ربات تلگرام رو اجرا نگه داره. گزینه‌های رایگان خوب:

### گزینه‌ی پیشنهادی: Railway یا Render

1. یه ریپازیتوری گیت‌هاب بساز و این فولدر رو توش push کن.
2. تو [railway.app](https://railway.app) یا [render.com](https://render.com) یه "Web Service" جدید از روی ریپازیتوری بساز.
3. متغیرهای محیطی (Environment Variables) رو ست کن:
   - `BOT_TOKEN` = توکنی که از BotFather گرفتی
   - `BOT_USERNAME` = یوزرنیم ربات، بدون @ (مثلاً `Sara_Birthday_bot`)
   - `FRIEND_PHONE` = شماره‌ی موبایل دوستت (هر فرمتی، فقط ۱۰ رقم آخرش مهمه)
   - `GIFT_CODE` = کد واقعی گیفت کارت پلی‌استیشن
   - `TOKEN_EXPIRY_MINUTES` = مثلاً `15` (اختیاری)
4. Start command: `npm start`
5. بعد از دیپلوی، یه آدرس مثل `https://your-app.up.railway.app` بهت می‌ده.

> نکته: پلن‌های رایگان بعضی سرویس‌ها بعد از مدتی بی‌کاری sleep می‌کنن. برای یه استفاده‌ی یه‌باره (کادو تولد) کاملاً کافیه، ولی برای اطمینان بهتره چند روز قبل از تولد یه تست کامل بگیری.

## مرحله ۴: ساخت QR کد

بعد از این‌که آدرس سایتت آماده شد (مثلاً `https://your-app.up.railway.app`)، با یه سایت رایگان مثل [qr-code-generator.com](https://www.qr-code-generator.com) یه QR کد از اون آدرس بساز و پرینتش کن.

## اجرای محلی (برای تست)

```bash
npm install
BOT_TOKEN=your_token BOT_USERNAME=Sara_Birthday_bot FRIEND_PHONE=09121234567 GIFT_CODE=PSN-1234-5678-9012 npm start
```

بعد `http://localhost:3000` رو باز کن.

## نکات امنیتی

- کد گیفت کارت رو مستقیم تو کد فرانت‌اند ننویس؛ همیشه از متغیر محیطی `GIFT_CODE` روی سرور استفاده کن.
- بعد از تولد، ربات رو غیرفعال کن یا سرویس رو متوقف کن تا کسی نتونه دوباره ازش استفاده کنه.
- این پروژه فقط برای یه نفر طراحی شده (یه کد OTP فعال در هر لحظه)، برای استفاده‌ی عمومی مناسب نیست.
