# هدیه‌ی تولد (نسخه‌ی کاملاً استاتیک، بدون سرور)

سایتی که فقط با یه فایل HTML کار می‌کنه. کد گیفت کارت داخل فایل، به‌صورت رمزنگاری‌شده، ذخیره می‌شه و فقط با وارد کردن شماره موبایل درست باز می‌شه. نه سرور لازمه، نه بات تلگرام، نه کارت بانکی.

## چطور کار می‌کنه

کد گیفت کارت با یه الگوریتم رمزنگاری استاندارد (AES-GCM) و با استفاده از شماره موبایل دوستت به‌عنوان کلید، رمزنگاری می‌شه. وقتی کسی تو سایت شماره‌ای وارد می‌کنه، مرورگر همون الگوریتم رو اجرا می‌کنه؛ اگه شماره درست باشه رمزگشایی موفق می‌شه و کد نمایش داده می‌شه، اگه غلط باشه رمزگشایی fail می‌شه و پیام خطا نشون داده می‌شه.

نکته: چون همه‌چیز تو خود فایل HTML اتفاق می‌افته (نه یه سرور)، هیچ بک‌اندی لازم نیست. فقط باید فایل رو یه‌جایی میزبانی کنی که قابل باز شدن با لینک باشه (مثل GitHub Pages).

## مرحله ۱: تولید کد رمزنگاری‌شده

روی کامپیوتر خودت (نه رو سایت، نه رو گیت‌هاب):

1. مطمئن شو Node.js نصبه (از [nodejs.org](https://nodejs.org))
2. فایل `generate-secret.js` رو دانلود کن
3. تو ترمینال، تو همون پوشه، بزن:
   ```
   node generate-secret.js
   ```
4. ازت شماره موبایل دوستت و کد واقعی گیفت کارت رو می‌پرسه؛ وارد کن
5. سه خط خروجی می‌گیری شبیه این:
   ```
   const SALT = "xxxxx...";
   const IV = "xxxxx...";
   const CIPHERTEXT = "xxxxx...";
   ```

## مرحله ۲: جایگزین کردن تو index.html

فایل `index.html` رو باز کن، دنبال این سه خط بگرد (نزدیک انتهای فایل):

```js
const SALT = "REPLACE_WITH_SALT";
const IV = "REPLACE_WITH_IV";
const CIPHERTEXT = "REPLACE_WITH_CIPHERTEXT";
```

با همون سه خطی که از مرحله‌ی قبل گرفتی جایگزینش کن، فایل رو ذخیره کن.

## مرحله ۳: میزبانی رایگان با GitHub Pages (بدون کارت)

1. تو همون ریپازیتوری گیت‌هابی که قبلاً ساختی، فایل `index.html` جدید (با مقادیر جایگزین‌شده) رو آپلود کن — می‌تونی جایگزین فایل قبلی بشه یا تو ریشه‌ی ریپو بذاریش
2. برو تو تنظیمات ریپازیتوری: بالای صفحه، تب **"Settings"**
3. تو منوی سمت چپ، بزن **"Pages"**
4. زیر "Build and deployment"، از منوی "Source" گزینه‌ی **"Deploy from a branch"** رو انتخاب کن
5. زیر "Branch"، `main` رو انتخاب کن و کنارش پوشه‌ی `/ (root)` رو بذار (اگه `index.html` رو تو ریشه گذاشتی)
6. بزن **"Save"**
7. چند دقیقه صبر کن، بعد بالای همون صفحه یه آدرس می‌بینی شبیه:
   `https://username.github.io/birthday-gift/`

همین آدرس رو برای ساخت QR کد استفاده کن.

## نکات امنیتی

- شماره موبایل و کد گیفت کارت هیچ‌وقت جایی ارسال نمی‌شن؛ همه‌چیز داخل مرورگر خود کاربر انجام می‌شه
- کسی که فایل HTML رو باز کنه (View Source) فقط متن رمزنگاری‌شده رو می‌بینه، نه خود کد گیفت کارت
- این روش در برابر حدس زدن شماره مقاوم نیست اگه کسی خیلی وقت داشته باشه (چون رمزگشایی سمت مرورگره)، ولی برای این‌که فقط دوستت لینک رو داره و شماره‌ش رو فقط خودش می‌دونه، کاملاً کافیه
- بعد از تولد، اگه خواستی می‌تونی ریپازیتوری رو دوباره Private کنی یا صفحه‌ی Pages رو غیرفعال کنی
